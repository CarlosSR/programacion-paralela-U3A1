# ParallelSum — README

Suma paralela de un arreglo grande de enteros.

## Requisitos
- **Java 17 o superior** (probado en OpenJDK 22.0.1, macOS M1, 16 GB RAM).
- Suficiente RAM para el arreglo (1,000M `int` ≈ 4 GB).

## Compilar
```bash
javac ParallelSum.java
```

## Ejecutar
```bash
java ParallelSum
```
